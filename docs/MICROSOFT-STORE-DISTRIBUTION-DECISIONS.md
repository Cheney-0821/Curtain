# Curtain Microsoft Store 发行决策记录

- 决策日期：2026-11-06
- 状态：已确定方向，暂缓实施
- 适用项目：Curtain（GPL-3.0-only）

## 项目性质与开发者身份

Curtain 是个人业余创作和开源分享项目。开发者没有公司或个体工商户主体，不以销售软件谋生，也不承诺长期稳定商业运营。项目初心是分享创作、增加交流机会和积累开发经验。

未来申请 Microsoft Store 开发者账户时，优先考虑 Microsoft Individual Developer 身份。是否能够使用个人身份完成中国地区的付款、税务和收款验证，必须以申请时微软 Partner Center 的实际政策与审核结果为准。

不为了上架或收款而预先注册公司或个体工商户。不得擅自把 Company 账户或营业执照设为项目发行的必要前提。

## Store 发行方向

优先方案：Microsoft Store 付费支持者版。

- GitHub 源码继续公开免费，采用 GPL-3.0-only。
- 官网 / R2 Direct 安装版本继续免费。
- Microsoft Store 版本如果个人开发者身份可以合规收款，则作为付费支持者版上架。
- Store 版与免费 Direct 版保持功能一致；付费是支持项目创作，不以功能锁定或订阅制造差异。
- 不因 Store 上架而引入不必要的订阅、独立支付系统或复杂授权后端。

备选方案：如果个人开发者身份无法合规收款，接受以免费方式上架 Microsoft Store。免费上架仍然有助于作品传播和交流。

## 实施优先级

Microsoft Store 不是当前开发阶段的紧急事项，也不得阻塞核心产品开发。

当前优先级仍然是：
- 打磨 Curtain 核心功能；
- 提高稳定性和直觉化交互；
- 解决真实用户反馈；
- 完善诊断与反馈体验；
- 在产品趋于成熟后再评估商店发行。

当前不实施 MSIX、Store 专用构建、商店自动更新适配、Partner Center 注册或收费系统。开发者会在产品成熟时主动重新开启 Store 发行讨论。

## 未来重新启动时必须重新核查

由于微软政策、个人账户资格、地区付款能力、税务表单和银行支持可能变化，未来启动前必须重新查阅官方资料并确认：

1. 中国大陆个人开发者是否仍可注册 Individual 账户并发布付费应用；
2. 个人开发者是否能将 Microsoft Commerce 收入结算至本人中国大陆银行账户；
3. 当时的 W-8BEN、美国预扣税、中国境内涉外收入申报要求；
4. Partner Center 对个人账户、发布者显示名称和收款人信息的要求；
5. MSIX 与 Curtain 当前全屏保护、窗口遮罩、全局快捷键、开机启动和诊断功能的兼容性；
6. Store 付费支持者版与免费 GPL Direct 版的商品说明和许可披露。

不得把此前的研究结果视为未来申请时仍然有效的政策保证。
