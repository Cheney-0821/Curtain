# Curtain 0.4.0

## 简体中文

- **局部清晰。** 在受保护的窗口内绘制一个或多个清晰区域。区域随窗口移动，区域内可以点击或滚动。
- **遮罩右键菜单。** 可以绘制清晰区域、调整模糊程度，或移除当前窗口的保护。
- **可选安装目录。** 安装时可以选择目录，应用内更新沿用当前安装位置。迁移后保留用户设置。

## English

- **Clear areas.** Draw one or more clear areas inside a protected window. They move with the window and remain clickable and scrollable.
- **Overlay context menu.** Draw a clear area, change the blur strength, or remove protection from the current window.
- **Custom installation folders.** Choose a folder during setup. In-app updates use the current installation location, and your settings are kept when you move Curtain.
