# Curtain 0.4.3

## 简体中文

- **多屏保护。** 可保护所有显示器、仅主显示器或指定副屏。手动保护与自动保护分别记住各自的范围。
- **窗口开关。** Windows 上下贴靠时，下方窗口的开关收入自身窗口。将鼠标移到上边缘即可唤出，移开后稍作停留再滑回。
- **局部清晰。** 微信表情面板沿用同一条清晰区边界，落在区域内的部分清晰，其余部分保持模糊。

## English

- **Multi-display protection.** Protect all displays, the primary display, or a specific secondary display. Manual and automatic protection remember their settings separately.
- **Window controls.** In a vertically snapped layout, the lower window keeps its control inside its own bounds. Move the pointer to the top edge to reveal it. The control stays visible briefly before sliding away.
- **Clear areas.** The WeChat emoji panel follows the same clear-area boundary as the main window. Parts inside the area stay clear, and the rest stay blurred.
